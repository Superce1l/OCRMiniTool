## 亮点

- **结果可编辑**：识别完成后切到「原文」即可直接改错字；改动只落在当前页
  （多页结果按页编辑，「全部」页签是整篇只读视图并给出提示），保存与复制
  都取改后的内容，结果区显示「已编辑」；批量模式逐项编辑后切走再切回不丢。
- **错误置顶**：识别失败、模型下载/加载失败、组件切换失败、设置保存失败等
  错误现在同时出现在页面顶部**可关闭的横幅**里（跨视图常驻，不随内容滚动），
  不再只有页面最底部的日志区；`logs/` 与页面日志照旧留档。
- **日志可排查**：每行日志带 `[pid=… 线程名]`，启动时写一行 header
  （版本 / pid / Python / 是否冻结版 / 系统 / 工作目录）；服务启动、原生窗口
  失败改 Edge、Edge 缺失改默认浏览器等回退路径都会落日志；HTTP 400/403 记
  WARN（403 带实际 Host/Origin），500 记 ERROR。
- **大文件护栏**：合并解析一次请求合计超过 **150 页**、批量模式单个文件超过
  **150 页**、或单文件超过 **512 MB** 时直接拒绝并说明怎么拆（HTTP 400），
  避免一次跑几小时、临时盘被占满；检查发生在「置忙」之前，被拒后不会卡在
  「已有任务进行中」。
- **输入更省心**：同一文件重复拖入/重复选择会自动跳过并提示；识别过程中
  提示词、选择文件/目录、清空、删除都会被锁住并说明「改动将在下次识别生效」。

## 行为变化（升级前请知悉）

| 变化 | 说明 |
|---|---|
| 日志行格式 | `时间 [级别] [pid=… 线程名] 消息`；按 `[INFO] 消息` 连读的外部 grep 脚本需要放宽 |
| 超限请求 | 合并模式按**总页数** 150 拦；批量模式按**单个文件** 150 页拦（不会被总页数误伤） |
| 「全部」页签 | 只读（逐页编辑请切到具体页签）；鼠标悬停有提示 |
| 识别失败 | 除日志外会出现顶部横幅；开始新一轮识别时自动收起 |

## 已知限制

- **显存 < 8 GB 的 NVIDIA 卡**：`自动` 会回落 CPU（小显存有性能悬崖，见 v1.3.2 说明）。
- **打包版不含 CLI**：`console=False` 没有控制台可写，CLI 只支持源码运行。
- **超大文件仍是「先上传后拒绝」**：>512 MB 的上传会先完整落到 `%TEMP%` 再被拦
  （multipart 解析阶段按 Content-Length 早拦留待后续）。
- **损坏 PDF 的页数不可知**：读不到页数时栏杆放行，随后由引擎报「缺 pymupdf / 解析失败」。
- **EXE 无版本资源文件**：右键属性里看不到版本号（D15，未做）。
