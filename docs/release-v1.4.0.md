# v1.4.0 — 键盘可用、粘贴截图、PDF 页范围、后处理质量、busy 语义 409

> 本版在 v1.3.3 的基础上继续做「每天都会用到」的能力：**不改模型、不加重依赖**；
> 有一处对外契约变化（忙时返回 HTTP 409），前端与服务端已同步。
> 状态：**代码已就绪，未打包/未发布**（等下一次构建窗口）。

## 亮点

- **键盘可用 + 读屏语义**：Ctrl/Cmd+Enter 开始识别、Esc 取消（仅识别中生效）；
  拖放区可用 Tab 聚焦、Enter/Space 打开选择框；历史删除支持 Enter/Space；
  进度条、日志区、结果概要补了 `role` / `aria-valuenow` / `aria-live`。
- **粘贴截图**：识别页 Ctrl+V 直接把剪贴板图片加入队列（命名为 `pasted-N.png`）；
  在提示词/结果编辑框内粘贴仍是普通文本，不会被拦截。
- **PDF 指定页范围**：设置页填 `1-3,5,10-` 就只识别这些页；与 CLI 的 `--pages`
  共用同一份解析（`page_range.py`），非法值被拒且不写盘；几百页 PDF 只选几页时，
  150 页护栏按**选中页数**计算，不会误拦。
- **后处理质量（可开关）**：合并段落断行、中英文之间补空格（默认关闭，跳过代码/表格/
  URL）；LaTeX 定界符 `\(..\)`/`\[..\]` 自动归一为 `$..$`/`$$..$$`；
  表格列数不一致时结果区提示「检测到 N 处表格列数不一致」（不再静默）。
- **busy → HTTP 409**：下载/加载/组件安装/识别忙时返回 409 + `{"error":{"message":…}}`，
  界面把「已有任务进行中」显示在顶部横幅；服务端记 INFO，不再当错误刷 ERROR。

## 行为变化（升级前请知悉）

| 变化 | 说明 |
|---|---|
| 忙时响应 | `POST /api/download`、`/api/load`、`/api/env/download`、`/api/recognize` 忙时由 200+`{ok:false}` 改为 **409**；按状态码分支的脚本需同步 |
| 新设置键 | `pdfPageRange`（默认 `""`）、`joinLines`（false）、`cjkSpacing`（false），自动迁移进旧 `settings.json` |
| 默认输出 | LaTeX 定界符会被归一（始终开启）；段落/空格两项默认关闭，需在设置页打开 |
| 提示条 | 「表格列数不一致」会与截断提示共用同一条结果横幅；「调大单页上限」建议只在截断/页数不符时出现 |

## 修复 / 顺手改掉

| 问题 | 说明 |
|---|---|
| 进度一开始就 100% | `setProgress(2, …)` / `setModelProgress(5, …)` 把百分数传给了按 0..1 比例的函数，识别/加载一开始就显示 100%；已改为 0.02/0.05 |
| CLI 与 GUI 页范围语义漂移风险 | 解析逻辑收敛到 `page_range.py` 单一实现，CLI 只是薄包装（错误文案不变） |
| 双份「页数」口径 | A9 护栏、引擎 PDF 展开、CLI 三处现在共用同一解析与夹取规则 |

## 已知限制

- **CLI 无 `join-lines` / `cjk-spacing` 开关**（本轮不做；GUI 设置不影响 CLI）。
- **CLI JSON 输出不含 `tableWarnings`**（只透传到 GUI 响应与批量 item）。
- 显存 < 8 GB 的 NVIDIA 卡仍自动回落 CPU；打包版仍无 CLI、EXE 仍无版本资源（沿用 v1.3.3）。
- 后处理的「去断行/中英空格」是启发式规则：诗歌、特殊排版、紧贴 URL 的文本可能不符合预期，
  已在设置项说明里提示；两项默认关闭。
